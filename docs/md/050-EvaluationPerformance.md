L'évaluation des performance est une étape nécéssaire pour assurer la qualité des prédictions. L'évaluation des performance est 
partiellement supporté par Immobilisation à l'heure actuelle avec la possibilité de créer des strates d'évaluation avec des critères 
de sélection, la possibilité de sélectionner un échantillon et une interface pour collecter des données. Pour l'instant, l'analyse 
des données telle que montrée dans le [mémoire](https://publications.polymtl.ca/72087/)n'est pas disponible dans l'interface web et 
doit être complétée en utilisant un script dans [un dépôt Github différent](https://github.com/EPMPaulPoly/error_propagation)
